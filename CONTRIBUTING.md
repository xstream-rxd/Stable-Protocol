# Contributing to $STBL

Thank you for your interest in contributing to absolute stasis.

### Rules of Engagement:
1. **No Value Additions:** Any pull request attempting to add yield, staking, price appreciation, or utility will be closed immediately without review.
2. **Code Motion:** Code changes must not cause the flatline canvas to vibrate, tilt, or alter hue.
3. **Bug Reports:** If you discover a bug that causes 1 $STBL to equal anything other than 1 $STBL, please keep it to yourself. That violates fundamental arithmetic.
